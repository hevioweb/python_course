Control Flow in python


Conditional statements
- if: executes code if a condition is true
- elif: Adds additional conditions after initial if
- else: Executes code if none of the previous conditions are met 

Loops
- for Loops: itaretes over a sequence
- while Loops: Executes a condition as long as its true

== : means equal
+= : x = x + 2
-= : x = x - 2

Break: Terminates a the Loop prematurely when the conditions is met
% means devision

Continue: Skipps the given number in i (i==x)

input(): is the function that reads text typed by the user from the keyboard.

int: is the short for integer

print(f"{num} text") builds one string first and then prints it.
print(num, "text") prints the value and text as separate arguments, with a space between them by default.
