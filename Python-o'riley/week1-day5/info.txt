Regular expressions dor Pattern Matching

- What are those: Regular expressions (often called regex) are a compact way to describe patterns in text.

They let you search for specific sequences of characters.
You can match simple text like "cat" or complex patterns like:
digits: \d+
email-like text: \w+@\w+\.\w+
words that start with a capital letter: [A-Z]\w*

- Why use them?

validate input (phone number, email, date)
find text inside strings
extract parts of text
replace patterns in text

- using the re module for these expressions

- common Functions: -re.search(patterns,string) serch for a specific thing in big texts
                    -re.findall(patterns,string) search for all specific things in big texts
                    -re.sub(patterns,replacement,string) replace old string with new one                   text = "I like apples."
                                                                                                           new_text = re.sub(r"apples", "oranges", text)
